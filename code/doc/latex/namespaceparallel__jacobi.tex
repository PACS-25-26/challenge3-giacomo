\item \begin{DoxyNote}{Note}

Given that the matrix row index \$i\$ represents spatial grid height (\$\+Y\$-\/axis) and column index \$j\$ represents width (\$\+X\$-\/axis), the internal loop correctly unrolls the sequential output stream to maintain physical spatial orientation.
