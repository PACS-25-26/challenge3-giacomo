Exports a 2D matrix solution to an ASCII VTK Legacy structured points file. 


\begin{DoxyItemize}
\item This function creates a structured grid representation (\$N \textbackslash{}times N \textbackslash{}times 1\$) where the Z-\/dimension is flattened. It maps the row-\/major Eigen matrix data into the coordinate system expected by VTK format rules.
\item \begin{DoxyNote}{Note}
VTK structures iterate over \$\+X\$ coordinates fastest, then \$\+Y\$, then \$\+Z\$. Given that the matrix row index \$i\$ represents spatial grid height (\$\+Y\$-\/axis) and column index \$j\$ represents width (\$\+X\$-\/axis), the internal loop correctly unrolls the sequential output stream to maintain physical spatial orientation.
\end{DoxyNote}
