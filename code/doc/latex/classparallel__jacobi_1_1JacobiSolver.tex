\doxysubsection{Detailed Description}
A parallel 2D Jacobi iterative solver utilizing hybrid MPI + Open\+MP parallelization. 


\begin{DoxyItemize}
\item This class solves elliptic partial differential equations (like the Poisson equation) on a uniform 2D grid. The domain is decomposed horizontally (by row blocks) among MPI processes, while internal matrix operations within each process can be accelerated using Open\+MP threads. 
\end{DoxyItemize}
