\doxysubsection{Detailed Description}
Spatial convergence and accuracy test for the parallel Jacobi Poisson solver. 


\begin{DoxyItemize}
\item This test script performs a Grid Convergence Study by solving the 2D Poisson equation on progressively refined grids (from n = 16 to n = 256). It leverages a hybrid MPI + Open\+MP approach, calculates the L2 error against the analytical exact solution, and logs the execution metrics. 
\end{DoxyItemize}
